Privacy Policy

Last updated: October 8, 2026

Purpose

Rclone Backup is a personal application configuration used to back up files from the owner's Windows computer to the owner's Google Drive account.

Google Drive Access

The application accesses Google Drive files and metadata to identify existing files, compare their contents, upload new files, and update changed files.

Data Storage and Security

Backup files are transferred directly between the owner's computer and Google Drive using rclone. Google authentication credentials are stored locally on the owner's computer.

Data Sharing

The application owner does not sell, distribute, or share Google Drive data with advertisers or other third parties. No independent backup server is operated by the application owner.

Use of Information

Google Drive information is used solely for the personal backup and synchronization operations authorized by the account owner.

Access Revocation

The account owner may revoke application access through Google Account security settings at any time.
